# quanttide-meta

量潮元工程（meta-engineering）

## 定位：哲学的实现

哲学回答「为什么、是什么」，是理论；元工程回答「怎么建、怎么运转」，是工程。二者的分工不是并列，而是上下游：哲学出命题，元工程把命题落成可运行的体系。

判断一条内容归谁：只讲命题本身，归哲学；讲命题如何落成结构、规则与工具，归元工程。工程规范应当能回溯到哲学命题——回溯不到，要么命题缺失，要么这条规范尚无依据。
