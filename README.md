# quanttide-meta
量潮元工程

## 结构

- `data/`：数据类子模块
  - `library` → [quanttide-library-of-philosophy](https://github.com/quanttide/quanttide-library-of-philosophy)
  - `roadmap` → [quanttide-roadmap-of-philosophy](https://github.com/quanttide/quanttide-roadmap-of-philosophy)
  - `journal` → [quanttide-journal-of-philosophy](https://github.com/quanttide/quanttide-journal-of-philosophy)
- `docs/`：文档类子模块
  - `tutorial` → [quanttide-tutorial-of-philosophy](https://github.com/quanttide/quanttide-tutorial-of-philosophy)
- `examples/`：示例类子模块
  - `default` → [quanttide-laboratory-of-philosophy](https://github.com/quanttide/quanttide-laboratory-of-philosophy)
